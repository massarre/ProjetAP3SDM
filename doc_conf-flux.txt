Conf internet 

Vlan 99 (Admin) est utlisé comme réseau entre le routeur et le switch : 10.1.1.0 /29

Liaison entre le routeur et le switch 
Interface du router vers le switch-16 : FastEthernet0/1 avec ip 10.1.1.1 
Interface du switch 16 vers routeur   : FastEthernet2/0/10 inclus dans le vlan 99 . L'ip du vlan est de  10.1.1.2

Sur le routeur

! Interface vers le switch
RTsdmap3(config)# interface port 0/1
RTsdmap3(config-if)# ip address 10.1.1.1 255.255.255.248
RTsdmap3(config-if)# ip nat inside
RTsdmap3(config-if)# no shutdown

! Interface Internet
RTsdmap3(config)# interface FastEthernet0/0
RTsdmap3(config-if)# ip nat outside
RTsdmap3(config-if)# no shutdown

! NAT Configuration
RTsdmap3(config)# ip nat inside source list 1 interface FastEthernet0/0 overload

! ACL pour NAT (inclure tous les réseaux locaux)
access-list 1 permit 10.1.1.0 0.0.0.7
access-list 1 permit 10.10.10.0 0.0.0.15
access-list 1 permit 10.20.20.0 0.0.0.31

! Route par défaut vers Internet
RTsdmap3(config)# ip route 0.0.0.0 0.0.0.0 FastEthernet0/0

! Routes vers les réseaux derrière le switch
RTsdmap3(config)# ip route 10.10.10.0 255.255.255.240 10.1.1.2
RTsdmap3(config)# ip route 10.20.20.0 255.255.255.224 10.1.1.2
! PAS de route pour 10.1.1.0/29 car directement connecté


Sur le Switch-16

! Activer le routage
SWT-16(config)# ip routing

! Créer le VLAN 99
SWT-16(config)# vlan 99
SWT-16(config-vlan)# name ADMIN
SWT-16(config-vlan)# exit

! Interface SVI pour le VLAN 99
SWT-16(config)# interface vlan 99
SWT-16(config-if)# description Liaison vers Routeur
SWT-16(config-if)# ip address 10.1.1.2 255.255.255.248
SWT-16(config-if)# no shutdown
SWT-16(config-if)# exit

! Configurer le port vers le routeur
SWT-16(config)# interface port 2/0/10
SWT-16(config-if)# description Vers RTR port 0/1
SWT-16(config-if)# switchport mode access
SWT-16(config-if)# switchport access vlan 99
SWT-16(config-if)# no shutdown
SWT-16(config-if)# exit

! Route par défaut vers le routeur
SWT-16(config)# ip route 0.0.0.0 0.0.0.0 10.1.1.1

! Routes pour les autres VLANs
SWT-16(config)# interface vlan 10
SWT-16(config-if)# ip address 10.10.10.1 255.255.255.240
SWT-16(config-if)# no shutdown

SWT-16(config)# interface vlan 20
SWT-16(config-if)# ip address 10.20.20.1 255.255.255.224
SWT-16(config-if)# no shutdown


Schema du explique de la configuration 

INTERNET
    │
    │ FastEthernet0/0 (NAT Outside)   
    │
ROUTEUR (RTR)
    │ port 0/1: 10.1.1.1/29 (NAT Inside)
    │
    │ VLAN 99 (10.1.1.0/29)
    │
SWITCH-16 (SWT-16)
    │ VLAN 99 SVI: 10.1.1.2/29
    │     (admin)
    ├── VLAN 10: 10.10.10.0/28
    │     (Clients)
    │
    └── VLAN 20: 10.20.20.0/27
