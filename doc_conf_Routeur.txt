2- Étapes de configuration SSH sur un routeur Cisco

Note : le routeur et la machine de Test doivent être sur le même réseau 
Définir un nom d’hôte et un domaine (obligatoire pour générer les clés RSA)


Router> enable
Router# configure terminal
Router(config)# hostname RTsdmap3 
RTsdmap3(config)# ip domain-name sdmap3.local


Créer un utilisateur avec mot de passe


username admin privilege 15 secret sdmap3


Générer les clés RSA pour SSH
 (choisir une taille de clé 1024 bits ou plus pour la sécurité)


crypto key generate rsa
The name for the keys will be: sdmpap3.local
How many bits in the modulus [512]: 2048


Activer l’accès SSH sur les lignes VTY


RTsdmap3(config)# line vty 0 4
RTsdmap3(config-line)# transport input ssh
RTsdmap3(config-line)# login local
RTsdmap3(config-line)# exit


(Optionnel) Limiter la version SSH
 Pour plus de sécurité :
RTsdmap3(config)# ip ssh version 2
